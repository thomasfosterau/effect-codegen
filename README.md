# effect-codegen

An experimental code generation library for [Effect](https://effect.website): language-agnostic documents and printing, with language ASTs and printers built on them.

> [!CAUTION]
> Experimental and pre-1.0, largely written with Claude Code. Nothing is published yet, and the API will change.

There is no code yet: this repository holds only its license and guidance. The `@thomasfosterau/effect-codegen*` packages currently live in [effect-loco](https://github.com/thomasfosterau/effect-loco). See [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) to contribute; agents also read [AGENTS.md](AGENTS.md).
